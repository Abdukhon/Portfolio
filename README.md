## Design-Philosophie

Mein Portfolio nutzt ein modernes Cyberpunk-Design mit:
- Neonfarbschema (#00c8fa)
- Responsive Layout (Mobile-First Approach)
- Glowing Effects und moderne Übergänge
- Dark Mode als Standard

## Responsive Design

Das Portfolio ist vollständig responsive und optimiert für:
- Desktop (1920px+)
- Tablet (768px - 1024px)
- Mobile (< 768px)
